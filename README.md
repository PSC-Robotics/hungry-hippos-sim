# Hungry Hippos simulator

A [Webots](https://cyberbotics.com) simulation of the arena for the PSC Robotics
Competition 2027 game, Hungry Hippos. You program the simulated robot with the PSC robot
library, the same way as a real robot. [The Simulated Robot](SIMULATED_ROBOT.md) describes
what the robot has and how to code it.

You can use it to try out your code before your robot is built, and for the Simulator
challenge.

## Install

1. Install [Webots R2025a](https://cyberbotics.com/#download).
   - On recent macOS versions the R2025a release can fail to start
     ([cyberbotics/webots#6976](https://github.com/cyberbotics/webots/issues/6976)). If it
     does, install a [nightly build](https://github.com/cyberbotics/webots/releases) instead.
2. Install [Python 3](https://www.python.org/downloads/) if you don't have it.
3. [Download the latest release](https://github.com/PSC-Robotics/hungry-hippos-sim/releases/latest/download/hungry-hippos-sim.zip)
   and unzip it. Or clone this repository:

   ```bash
   git clone https://github.com/PSC-Robotics/hungry-hippos-sim.git
   ```

## Run it

Open `worlds/hungry_hippos.wbt` in Webots (**File → Open World**). On macOS or Linux you can
also run:

```bash
./run.sh
```

Press play if the simulation starts paused. The robot waits for the start button: click the
3D view and press **S**, or wait 2 seconds and it starts by itself.

If Webots says it can't find Python, set the Python command in Webots' preferences
(**Preferences → General → Python command**) to your Python 3, for example `python3`, or
`py -3` on Windows.

## Write your code

Your code goes in `controllers/psc_robot/robot.py`. It starts with a short example that
shows how to use the wheels, grabber, camera, LED and buzzer. Change it, save it, then press
**Reset Simulation** in Webots to run it again.

The robot is wired like this:

| Part | How to use it |
| --- | --- |
| Left wheel | `robot.brain.dc_motor(20, 21)` |
| Right wheel | `robot.brain.dc_motor(19, 4)` |
| Grabber jaws | `robot.brain.servo_driver(sda=17, scl=27).servos[0]` and `.servos[1]`: -1 is open, 1 is closed |
| Camera | `robot.camera.see()` |
| LED | `robot.brain.led.colour` |
| Buzzer | `robot.brain.buzzer.buzz(frequency, duration)` |

As in a match, the robot is stopped 150 seconds after the start button.

### Autocomplete

Open this folder in [Visual Studio Code](https://code.visualstudio.com) with the
[Python extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python).
The folder's `.vscode/settings.json` points it at the simulated robot library in
`controllers/psc_robot/sr`, so typing `robot.` or `robot.brain.` in `robot.py` lists what's
available, with its documentation. Other editors that use Pyright, such as Zed or Neovim,
pick up the same setting from `pyrightconfig.json`.

## Trying corner 1

The robot starts in corner 0. To start in corner 1, select the robot in the scene tree
on the left in Webots and set:

| Field | Value |
| --- | --- |
| `translation` | `1.98 -2.23 0` |
| `rotation` | `0 0 1 3.14159` |
| `controllerArgs` | `"1"` |
| `flagColor` | `0.92 0.27 0.81` |

Save the world, then reset the simulation. `robot.zone` is then 1.

## What's here

| Path | What it is |
| --- | --- |
| `controllers/psc_robot/robot.py` | Your robot code. |
| `controllers/psc_robot/sim_wiring.py` | Which pins and boards drive which part of the robot. |
| `controllers/psc_robot/sr/robot3/` | The simulated robot library: the same API as the real one. |
| `controllers/psc_robot/psc_robot.py` | Runs `robot.py`, as the real robot runs the code on its USB stick. |
| `protos/SimpleRobot.proto` | The robot: two wheels, a two servo grabber, two LEDs, a buzzer, a camera and a flag. |
| `worlds/hungry_hippos.wbt` | The arena. It's generated by `tools/build_arena.py`, so change that rather than this file. |
| `tools/build_arena.py` | Generates the world and its textures. The arena's dimensions are at the top. |

To rebuild the world after changing the generator:

```bash
pip install opencv-python numpy pillow
python3 tools/build_arena.py
```

## Differences from the real game

- **Assumed values:** the rule book doesn't give the wall thickness (20mm here), token mass
  (150g) or token friction (0.5), so these are guesses. The robot's own dimensions are made up.
- **Navigation:** as on a real robot, the robot finds its way with the camera, which sees the
  `tag36h11` markers on the walls and tokens. There's no GPS or compass.
- **Marker patterns:** these are generated from the marker IDs. Token IDs are picked at random
  from 20 to 100.
- **Match time:** the 150 second timer starts when your code presses or waits for the start
  button. To turn it off, set `GAME_TIMEOUT` to `None` in
  `controllers/psc_robot/sr/robot3/__init__.py`.
- **Perfect sensors and motors:** there's no noise, so real robots will be less accurate.
- **Scoring:** nothing keeps score in the simulation yet.

The rule book is the final word on the game: see
[psc-robotics.uk/competition/rules](https://psc-robotics.uk/competition/rules).
